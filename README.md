# 묵상셀 · 비공개 묵상 자료실

교회 묵상 나눔을 녹음한 뒤 AI로 정리·검토한 문서를, 승인된 구성원끼리 공유하기 위한 기능형 프로토타입입니다.

## 실행

별도 설치 없이 `index.html`을 열거나 로컬 서버로 실행합니다.

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

접속 주소는 `http://127.0.0.1:8765`입니다.

## 체험 방법

로그인 화면에서 이름을 입력하면 진행자 권한으로 입장합니다. `이름 저장`을 선택하면 같은 브라우저에서 다음 방문 시 이름이 자동으로 표시됩니다.

## 구현 기능

- 이름 기반 간편 입장과 이름 저장
- 교인 / 진행자 / 관리자 역할 구분
- 진행자·관리자만 자료 등록 화면 노출
- PDF, Word, TXT, Markdown 파일 업로드
- 자료 제목, 날짜, 진행자, 말씀 본문, 공개 대상, 소개 등록
- 녹음·공유 동의와 AI 결과 검토 확인 필수
- IndexedDB에 파일 보관 및 다시 다운로드
- 검색과 그룹별 필터
- 진행자는 본인 자료, 관리자는 모든 자료 삭제
- 모바일 반응형 화면

## 실제 서비스에 필요한 연결

현재 계정·권한·파일은 한 브라우저 안에서만 동작합니다. 여러 사람이 인터넷에서 함께 사용하려면 아래 작업이 필요합니다.

1. Supabase Auth 개인별 로그인과 관리자 가입 승인
2. 교회·그룹·구성원·자료 데이터베이스
3. Supabase Storage 비공개 버킷
4. Row Level Security를 이용한 그룹별 열람·등록 정책
5. 다운로드 만료 링크와 관리자 감사 기록
6. 개인정보 처리방침, 녹음 동의 및 자료 보존·삭제 기준
